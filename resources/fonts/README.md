# قلم‌های محلی

`butterfly.woff2` نشان‌واژه‌ی لبه‌های قاب را می‌نویسد (`.frame-mark` در
`app.css`). تنها جایی است که این قلم به کار می‌رود؛ متن سایت با Vazirmatn و
InterVar ست می‌شود و آن‌ها از `node_modules` می‌آیند.

`butterfly.ttf` نسخه‌ی اصلی است و سرو نمی‌شود — فقط برای اینکه تبدیل دوباره
قابل تکرار باشد:

```bash
pip install fonttools brotli
python3 - <<'PY'
from fontTools import subset
o = subset.Options()
o.flavor = 'woff2'
o.layout_features = ['*']      # قلم شکسته است؛ لیگاتورها و پیوندها باید بمانند
f = subset.load_font('resources/fonts/butterfly.ttf', o)
s = subset.Subsetter(options=o)
s.populate(unicodes=list(range(0x41, 0x5B)) + list(range(0x61, 0x7B)) + [0x20])
s.subset(f)
subset.save_font(f, 'resources/fonts/butterfly.woff2', o)
PY
```

زیرمجموعه‌گیری اختیاری نیست: قلمِ کامل ۷۳ کیلوبایت است و با `font-display:
block` بارگذاری می‌شود، یعنی تا رسیدنش نشان نامرئی است. با محدودکردن به
`A-Z a-z` و فاصله، ۴۶ کیلوبایت می‌شود و هیچ حرفی از «Kianbehsaz» کم نمی‌آید.

قلمی لاتین است و هیچ حرف فارسی ندارد — بلوک عربی/فارسی در آن صفر گلیف دارد.
به همین دلیل `unicode-range` آن در `app.css` به `A-Z` و `a-z` محدود شده تا
مرورگر برای متن فارسی سراغش نرود.

## سه عددی که به این قلم گره خورده‌اند

اگر قلم عوض شد، این سه با هم باید دوباره اندازه گرفته شوند — هیچ‌کدام از
جدولِ متریکِ قلم درنمی‌آید، چون آن جدول با جوهری که مرورگر می‌کشد نمی‌خواند
(Butterfly ascent را ۲٫۷۰۳ اعلام می‌کند ولی جوهرِ واقعی ۱٫۴۸em است):

| عدد | کجا | معنی |
|---|---|---|
| `1.48` | `--shell-gap` | ضخامت نوارِ چرخیده ÷ اندازه‌ی قلم |
| `0.74` | `--frame-mark-reach` | نصفِ همان، برای نشاندنِ نشان وسطِ حاشیه |
| `0.045em` | `translateY` در `.frame-mark-right/left` | جبرانِ ناقرینگیِ کرسی |

روشِ اندازه‌گیری: کلمه در اندازه‌ی ۱۰۰ پیکسل روی زمینه‌ی سیاه رسم شود، کادرِ
جوهرش پیکسل‌به‌پیکسل پیدا شود، و نسبت‌ها از همان بیرون بیایند. `measureText`
کانواس اینجا جواب نمی‌دهد: برای همین قلم عرضی گزارش می‌کند که با چیدمانِ
واقعیِ DOM دو برابر فرق داشت.

`--frame-mark-size` هم به قلم وابسته است. Butterfly در هر em دو برابرِ قلمِ
پیشین کشیده است (۷٫۴۵ برابرِ اندازه در برابر ۳٫۷۹)، پس با نصفِ اندازه همان
بلندی روی صفحه درمی‌آید.
